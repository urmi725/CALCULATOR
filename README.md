# Simple Calculator

This project is a simple calculator application built with Python, offering both a command-line interface (CLI) and a full-featured graphical user interface (GUI).

## Features

- **Basic Arithmetic**: Perform addition, subtraction, multiplication, and division.
- **CLI Version**: A lightweight, terminal-based calculator for quick calculations.
- **Full-Featured GUI**: A modern, stylish calculator with a display, number pad, and operator buttons.
- **Advanced Operations**: The GUI version includes buttons for clearing the entry, backspace, and percentage calculations.

## Usage

### Command-Line Version

To run the CLI version, execute the following command:

```sh
python calculator.py
```

The script will prompt you for two numbers and an operator.

### GUI Version

To launch the graphical calculator, run:

```sh
python calculator_gui.py
```

## Technologies Used

- **Python**: Core programming language.
- **Tkinter**: For the graphical user interface.
